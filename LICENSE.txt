10. Data

The Software sends us an API key, a device identifier, a count of calls, and the build
version it is running; when you sign a machine in, it also sends the name that machine
reports for itself. These licensing requests do not include your drawings, file paths,
prompts or tool arguments. If you choose to submit a support report, its supplied text,
selected attachments and any opted-in contact address are emailed to the maintainer and
retained for three months from receipt.

The npm launcher installs or updates the plugin in your Autodesk auto-load folder and
removes legacy CADBridge bundles there. The plugin enables AutoCAD command logging so
the MCP server can read local command output. These log files remain on your computer;
Control does not automatically delete them or upload them to us. Your MCP client
controls how it shares tool results with its AI provider. The Privacy Policy describes
these flows and what we retain.
